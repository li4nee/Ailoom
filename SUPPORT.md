# Getting help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/li4nee/ailoom/discussions). This includes "how do I", configuration help, and feature proposals.
- **Bugs:** open an [issue](https://github.com/li4nee/ailoom/issues) using the bug form. Issues are for bugs only; please ask questions in Discussions instead.
- **Security problems:** do not post them publicly. Follow [SECURITY.md](SECURITY.md).
- **Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Before you ask, check the [documentation](README.md#documentation) and search existing discussions and issues.
