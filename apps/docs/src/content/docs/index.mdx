# AiLoom

AiLoom is a customer support platform built for self-hosting. It combines AI-powered chat, a knowledge base, conversation hand-off to human agents, and usage tracking into a single open-source (AGPL-3.0-only) application.

AiLoom is available as a public beta. The application is self-hosted rather than a managed SaaS;
operators own deployment, data, backups, and model-provider configuration.

## What's inside

- **AI chat** — Vercel AI SDK powered streaming conversations with provider-agnostic model access (OpenAI, Anthropic, Gemini, Groq, Mistral, Ollama, and more).
- **Knowledge base** — Document ingestion with pgvector semantic search and per-dimension HNSW indexes.
- **Knowledge freshness** — Scheduled crawls, stale and unreachable reports, version diffs, and editing for text and file sources. See [Knowledge freshness and versions](/knowledge-freshness/).
- **Conversation management** — Contacts, conversations, messages, and hand-off from AI to human agents.
- **Agent productivity** — Priority routing, customer context, saved replies, private notes, and reviewed AI drafts.
- **Usage tracking** — Daily token and request tracking per workspace and bot, with model pricing.
- **Provider credentials** — Secure storage of API keys per workspace.
