## Start locally

You need Docker Compose, Node 24, and pnpm. The first signup becomes the instance admin.

```sh
git clone https://github.com/li4nee/ailoom.git && cd ailoom
cp .env.example .env
# Set PUBLIC_URL, HTTP_PORT, and the POSTGRES_* values in .env.
# For local HTTP, use PUBLIC_URL=http://localhost:8080 and HTTP_PORT=8080.
pnpm secrets:generate
# Paste the generated secrets into .env.
docker compose -f deploy/docker-compose.yml --env-file .env up -d --build --wait
```

Open `PUBLIC_URL`, create your account and workspace, then add a bot and a knowledge source.
The [getting started guide](/getting-started/) explains the first bot, widget setup, and local
development. For a production host, start with [self-hosting](/self-hosting/).

<aside class="home-boundary">
  <h2>Clear limits are part of the design</h2>
  <p>
    AiLoom supports knowledge answers and human handoff. It does not promise an unattended agent
    that performs arbitrary account actions. Remote MCP is a client for one selected read-only tool;
    AiLoom does not expose an MCP server.
  </p>
</aside>

AiLoom is in public beta. Review the [FAQ](/faq/) and [data handling guide](/data-handling/) before
using it with customer data.
