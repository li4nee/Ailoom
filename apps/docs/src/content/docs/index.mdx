## Built for self-hosting

- **Your deployment, your data.** Run AiLoom on your own infrastructure with PostgreSQL and pgvector.
- **Your model choice.** Connect supported hosted providers, Ollama, or another OpenAI-compatible endpoint.
- **Approved context and actions.** Configure bot knowledge and tightly scoped read-only API or MCP tools.
- **A clear product boundary.** AiLoom supports knowledge answers and human handoff; it does not promise an unattended agent to perform arbitrary account actions.

AiLoom is in public beta. See the [FAQ](/faq/) and [data handling guide](/data-handling/) before using it with customer data.
