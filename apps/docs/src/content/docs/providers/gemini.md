# Google Gemini

1. Create an API key in Google AI Studio: <https://aistudio.google.com/app/apikey>.
2. Add a credential with provider **Google Gemini**.
3. Pick `gemini-3.8-flash` for most bots. For higher quality, select a Pro model available to your
   API key.
4. Embeddings: `gemini-embedding-001` or `text-embedding-004`.
