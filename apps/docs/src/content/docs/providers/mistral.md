# Mistral

1. Create a key at <https://console.mistral.ai/api-keys>.
2. Add a credential with provider **Mistral**.
3. Choose `mistral-small-latest` or `mistral-large-latest`.
4. `mistral-embed` is available for embeddings.

Chat and embeddings can use separate credentials or the same key.
