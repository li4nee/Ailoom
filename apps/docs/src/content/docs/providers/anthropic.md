# Anthropic

1. Create a key at <https://console.anthropic.com/settings/keys>.
2. Add a credential with provider **Anthropic**.
3. Choose `claude-haiku-4-5` for low latency or `claude-sonnet-4-5` for harder questions.

Anthropic provides chat only. Pair it with OpenAI, Gemini, Ollama, or the built-in local
model for embeddings.
