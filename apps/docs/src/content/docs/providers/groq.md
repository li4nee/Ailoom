# Groq

1. Create a key at <https://console.groq.com/keys>.
2. Add a credential with provider **Groq**.
3. Pick `llama-3.1-8b-instant` for speed or `llama-3.3-70b-versatile` for quality.

Groq provides chat only; use another provider or the built-in local model for embeddings.
