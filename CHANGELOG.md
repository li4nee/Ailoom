### Performance

- Corrected the TTFT benchmark pacing to model concurrent visitors without synchronized bursts.

- Added admin controls for CRM connections, signed webhooks, delivery replay, transcript-sharing
  disclosure, and provider base URLs.
- Enforced `integrations:manage`, `webhooks:read`, and `webhooks:write` scopes for API-key access
  to integration routes.
- Published the integrations, event envelope, webhook verification, and data-sharing guidance.
