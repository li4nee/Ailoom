# Changelog

## Unreleased

This section tracks changes after the latest public beta baseline. Release notes and version
tags are generated by release-please.

### Agent productivity

- Added conversation assignment, priority filters, customer context, workspace saved replies, and
  private internal notes.
- Added asynchronous handoff summaries and cited reply suggestions with explicit agent review and
  no automatic sending.
- Added deterministic AI-assistance safety fixtures, a manual live-provider release rubric, and
  workspace-scoped operational aggregates.

### Performance

- Reduced database round trips in chat orchestration, conversation admission, and vector search.
- Corrected the TTFT benchmark pacing to model concurrent visitors without synchronized bursts.
- Measured 343 requests with zero failures at p95 46.4 ms on the reference stack.

### Integrations

- Added admin controls for CRM connections, signed webhooks, delivery replay, transcript-sharing
  disclosure, and provider base URLs.
- Enforced `integrations:manage`, `webhooks:read`, and `webhooks:write` scopes for API-key access
  to integration routes.
- Published the integrations, event envelope, webhook verification, and data-sharing guidance.
