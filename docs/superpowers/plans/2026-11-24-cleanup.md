# Docs and Large-File Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the docs in line with v0.1.0 and split the three largest hand-written files without
changing behaviour.

**Architecture:** Pure refactors and doc edits. Each split keeps every public import path working
through the existing barrel or the original file re-exporting the new modules.

**Tech Stack:** TypeScript, React 19, NestJS 11, Vitest.

**Spec:** `docs/superpowers/plans/2026-11-24-00-phase2-index.md`.

## Global Constraints

See the index. No behaviour change: the existing tests are the safety net, and no test file
changes except import paths.

## Review Focus

1. A component split that changes render order or keys loses focus after a mutation. Keep the existing admin integrations tests passing unchanged.
2. A strings split that changes a key makes a label render as `undefined`. Typecheck catches it only if the split keeps the `as const` object type.
3. A service split that creates a circular Nest provider dependency fails at boot, not in unit tests. Run the API integration suite.
