## Global Constraints (every plan)

Copied from `2026-11-09-00-index.md`; every task's requirements include these.

- Node 24, pnpm via `packageManager`, TypeScript strict, no `any`, no non-null assertions outside tests, `assertNever` on every union `switch`.
- PostgreSQL 18 + pgvector ≥ 0.8; primary keys `default uuidv7()`; TypeORM 0.3.x with `synchronize: false`; raw SQL only inside `*.repository.ts` with a comment explaining why.
- Tenant tables are accessed only through `TenantRepository<T>` subclasses whose methods take `workspaceId` first; every new route is added to the route-isolation inventory.
- Only `apps/api/src/common/config/` reads `process.env`. Only `apps/api/src/providers/` imports `ai` / `@ai-sdk/*`.
- Outbound HTTP to user-supplied URLs only through `safeFetch`.
- API: JSON camelCase; error envelope `{ error: { code, message, details?, requestId } }`; cursor pagination `{ data, nextCursor }`.
- All day/month buckets in UTC; business code uses the injected `Clock`.
- Integration tests use real Postgres via Testcontainers and the `mock` provider; no real network.
- First line of every source file is the SPDX header (`AGPL-3.0-only` in `apps/*`, `MIT` in `packages/*`).
- Each new runtime dependency is justified in the PR description (what, why, license, size).
- Admin copy lives in `apps/admin/src/strings.ts` (or the per-feature string modules after the cleanup split); widget copy goes through the widget i18n catalog.
- Every migration has `down()`, passes `pnpm db:check`, and is covered by the upgrade test.
- Never mention any company other than the copyright holder in files, headers, or metadata.

## Shared conventions for these plans

- **Commands:** `pnpm --filter @app/api test:unit <path>`, `pnpm --filter @app/api test:int <path>`, `pnpm --filter @app/admin exec vitest run <path>`, `pnpm --filter @app/widget exec vitest run <path>`, `pnpm --filter @app/shared exec vitest run <path>`, `pnpm db:generate` / `pnpm db:check`.
- **Shared contracts** (Zod schemas and DTO types) go in `packages/shared/src/<feature>.ts` and are re-exported from `packages/shared/src/index.ts`.
- **Roles:** owner and admin manage settings; agents act on conversations. Each plan states its role matrix.
- **Audit:** every settings change and every approve/reject writes an audit row through `AUDIT_LOG`.
