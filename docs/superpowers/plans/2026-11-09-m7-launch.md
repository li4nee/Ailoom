# Milestone 7 — Launch Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything an operator needs to trust and run `v0.1.0`: realistic seed data, backups that restore, diagnostics, retention, proof that secrets never leak, measured performance, a tested upgrade path, signed multi-arch releases, complete docs — then every spec §26 launch criterion verified and the tag cut.

**Architecture:** spec §19 (cleanup jobs), §21–§24, §26; architecture §8.2, §9, §10.3.

**Tech Stack:** pg_dump/pg_restore, age, pg-boss schedules, autocannon, Docker Buildx + QEMU, release-please, cosign, Syft (via Buildx SBOM), OWASP ZAP baseline, Semgrep, ffmpeg.

**Spec:** `docs/spec.md`, `docs/architecture.md`. Index: `2026-11-09-00-index.md`.

## Global Constraints

All index constraints apply. Milestone-specific:

- Performance targets (single 2 vCPU / 4 GB host): platform TTFT overhead p95 < 300 ms at 20 concurrent conversations; retrieval query p95 < 50 ms with 100k chunks.
- Retention defaults: conversations `0` (keep forever), traces `90` days.
- Release images: `linux/amd64` and `linux/arm64`, SBOM + provenance attached, cosign keyless signature, tags `vX.Y.Z`, `X.Y`, `latest`.
- `restore.sh` refuses a non-empty database without `--force`.

## Review Focus (this milestone)

1. **Backup taken while the worker is writing.** Expected: `pg_dump` snapshot is consistent; files tarball may include blobs without rows (harmless) but never rows without blobs — so the DB dump runs **after** the files tarball. → Task 7.2 test.
2. **Operator upgrades skipping a version** (v0.1.0 → v0.3.0). Expected: migrations run in order; no "expand → contract" step assumes an intermediate release ran. → documented rule + Task 7.7 job runs from the oldest supported tag.
3. **Retention deleting conversations that are still open.** Expected: only conversations whose `last_message_at` is older than the cutoff **and** status `closed` or idle `ai` are deleted; `needs_human`/`human` are never auto-deleted. → Task 7.4 test.
4. **Diagnostics page on an instance with email disabled and no local model.** Expected: each check shows a clear state and fix hint; the page never 500s because one check throws. → Task 7.3 test.
5. **Secrets in error messages from providers** (some APIs echo the key prefix in 401 bodies). Expected: never stored in `last_error`, traces, logs, or responses. → Task 7.5 test.

- Modify: `.github/workflows/ci.yml` (job `backup-restore`, runs on changes to `deploy/**` and nightly)

**Interfaces:**

- Produces:
  - `backup.sh [--out DIR] [--age-recipient KEY]` → `DIR/<project>-backup-<UTC timestamp>/` containing `files.tar.gz` (from `files_data`, taken first) and `db.dump` (`pg_dump --format=custom` via `docker compose exec -T postgres`), `manifest.json` (`{ version, createdAt, sha256 per file }`); with `--age-recipient` both files are encrypted to `*.age` and plaintext removed
  - `restore.sh BACKUP_DIR [--identity FILE] [--force]` → verifies checksums, refuses if the DB has any table in `public` with rows unless `--force`, stops `api`/`worker`, restores files then DB (`pg_restore --clean --if-exists`), runs `migrate`, starts services
  - Exit codes: 0 ok, 2 refused (non-empty), 3 checksum mismatch, 1 other

- [ ] **Step 1: Write the test script** — bring up stack A, seed, add a file source, run `backup.sh`; bring up empty stack B (different project name), run `restore.sh` → logging in as `dev@example.com` works, the file source's document opens, chat answers; running `restore.sh` again without `--force` → exit 2; tamper one byte → exit 3; encrypted backup round-trip with a throwaway `age` key.
- [ ] **Step 2: Implement scripts** (`set -euo pipefail`, `shellcheck` clean).
- [ ] **Step 3: Run** `bash deploy/scripts/backup-restore.test.sh` → `backup-restore: ok`.

**Interfaces:**

- [ ] **Step 1: Write failing tests** — cutoff boundary exact to the second (`FixedClock`); open human conversations survive; usage_daily unchanged after trace deletion; `0` days disables conversation retention; revoked-session rows inside the reuse-detection window (10 s) are never removed by cleanup.
